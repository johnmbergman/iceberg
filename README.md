# Iceberg Game Engine (Java)
Iceberg is an open-source, Java-based video game engine built on LWJGL.
It is developed by me (John Bergman) to experiment with building a lightweight game engine.
I do not plan to add any advanced game features, but I do plan to support simple 2D and even 3D game development.

If you are interested in serious game development, this library is probably not for you.
However, if you are interested in understanding basic game development concepts, and how to develop around OpenGL bindings, this repository may contain code that will be interesting to you.

Feel free to take a look through the source code, or even fork and submit pull requests!
